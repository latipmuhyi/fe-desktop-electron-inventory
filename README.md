
## Cara Menjalankan
1. Clone repo ini
2. Jalankan `npm install`
3. Buat folder services
4. Buat file env.js
5. Lalu faste sintak ini di dalam file tersebut "const base_url = "url-BE";"
6. Jalankan `npm start`
   

## Cara Build .exe
1. Buka Terminal/Powershell -> Run as administrator
2. Masuk ke directory project
3. Jalankan npm run build
